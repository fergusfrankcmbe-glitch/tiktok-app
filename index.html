Video Draft Uploader

A personal tool that uploads video files from my own computer to my own TikTok drafts inbox, so I can review and publish them from the TikTok app.

It is used by a single person on a single account and is not offered to anyone else.

What it does

  • Sends a local video file to the TikTok drafts inbox via the Content Posting API
  • Nothing is published automatically — every post is reviewed and published manually inside the TikTok app
